# sau

Утилита командной строки для загрузки переводов на smotret-anime.online (Anime 365).

Публикация серии озвучки через веб-форму сайта требует ручных шагов, а заливка
видеофайла на гигабайт занимает часы и рвётся при обрыве связи. `sau` делает то же
самое одной командой: заходит на сайт, разрезает файл на части, заливает их
параллельно с переключением между зеркалами, докачивает после обрыва и отправляет
форму.

## Состояние

Проектирование завершено, реализация не начата.
