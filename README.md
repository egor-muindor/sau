# sau

Утилита командной строки для загрузки переводов на smotret-anime.online (Anime 365).

Публикация серии озвучки через веб-форму сайта требует ручных шагов, а заливка
видеофайла на гигабайт занимает часы и рвётся при обрыве связи. `sau` делает то же
самое одной командой: заходит на сайт, разрезает файл на части, заливает их
параллельно с переключением между зеркалами, докачивает после обрыва и отправляет
форму.

## Состояние

Реализация завершена. Все пакеты покрыты тестами, которые работают без сети.
Отдельно есть ручной контрактный тест против живого сайта под тегом сборки
`live`: он заливает небольшой файл и удаляет его, форму не отправляет. Автоматически
не запускается и на момент написания не запускался ни разу.

## Установка и первый запуск

```
go build -o sau ./cmd/sau
sau login
sau upload episode-05.mkv --episode 5 --series 1234
```

Вход нужен примерно раз в месяц: сессия живёт долго, а `sau login --check`
отвечает, жива ли она ещё.

Постоянные для тайтла значения — идентификатор сериала, тип серии, тип перевода,
авторов, канал — удобнее один раз положить в `.sau.toml` в папке онгоинга, тогда
на каждую серию остаётся только файл и номер.

В окружении без консоли пароль берётся из `SAU_PASSWORD` или из файла, путь
к которому задан в `SAU_PASSWORD_FILE`.

Полный список команд, флагов и кодов возврата — в
[architecture.md §6](docs/architecture.md).
