# Правила проекта

## Коммиты

- **Подпись GPG обязательна** для коммитов и тегов. Ключ и автор заданы локально
  в конфиге репозитория — брать оттуда, не полагаться на глобальный конфиг
  и не подставлять значения самостоятельно.
- **Текст коммитов только на английском.** Без исключений.
- Коммитить и пушить только по явной просьбе.

## Что хранится в репозитории

Только документация по **протоколу** и по **инструменту**:

- `docs/protocol.md` — протокол сайта;
- `docs/architecture.md` — устройство утилиты;
- `README.md`, `CLAUDE.md`;
- исходный код и тестовые данные.

**Не хранить в репозитории:**

- документы и артефакты superpowers (спецификации, планы выполнения, чек-листы);
- планы реализации и материалы исследований;
- сырые захваты трафика, дампы страниц, скриншоты, профили браузера.

Выводы из планов и исследований должны быть **обёрнуты в документацию** и попадать
в `docs/`. Сам процесс — нет. Рабочие материалы держать в `.work/` (в `.gitignore`).

## Разработка

- Язык — Go, поставка одним исполняемым файлом.
- **TDD: тесты пишутся первыми.** Цикл, затрагивающий больше двух пакетов, —
  это два цикла.
- Поддерживаются macOS, Linux и Windows. Платформенные различия разводить
  тегами сборки, а не проверками во время выполнения; тесты, не имеющие смысла
  на платформе, не должны на ней компилироваться.

## Инварианты, которые нельзя нарушать

Каждый из них выведен из наблюдения за реальным обменом. Нарушение ломает
работу молча — см. `docs/protocol.md`.

- **Upload-серверы никогда не кэшируются.** Ни в конфиге, ни в состоянии.
  Парсятся из свежей страницы формы перед каждой заливкой.
- **Пароль не попадает в конфиг, состояние, cookie-файл и логи.** Это обеспечивается
  конструкцией типа, а не дисциплиной вызывающего кода. Весь HTTP идёт через
  один транспорт с редактором.
- **Публичный API не является источником истины о факте отправки формы.**
  Запись появляется с задержкой в минуты. При неизвестном исходе отправки
  автоматический повтор запрещён — решает человек.
- **Идентификатор сервера сам по себе не определяет, где лежат чанки** — канал
  раздачи меняет набор хостов, не меняя идентификатор. Для докачки должны
  совпасть оба.
- **Адрес в скрытом поле формы склеивается дословно**, как это делает сценарий
  сайта, включая двойной слэш. Нормализация — только для HTTP-запросов.
